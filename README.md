📊 Zepto Sales Report – Power BI Dashboard
🧾 Overview

This Power BI dashboard provides a comprehensive analysis of Zepto’s sales performance, focusing on key revenue metrics, category trends, and geographic insights. The goal of this report is to help identify top-performing categories, understand discount impact, and evaluate influencer-driven sales effectiveness.

📈 Key Insights

Total Revenue: 6M

Average Discount: 4.92%

Top Categories by Revenue: Snacks, Beverages, Grocery

High Revenue Products: Coca-Cola 1L, Maggi Noodles, Nescafe 100g

Influencer Impact: 28.78% of total revenue generated via influencer campaigns

Geographical Insights: Major sales concentration in metro cities like Mumbai, Delhi, Bengaluru, and Hyderabad

🧩 Dashboard Features

Category-wise Revenue Breakdown (Pie Chart)

Revenue by Discount Analysis (Bar Chart)

Original Price by Product (Column Chart)

Influencer Activity Revenue Comparison (Donut Chart)

Orders by Category (Bar Chart)

Geo-Map Visualization showing city-level sales distribution

🛠️ Tools & Technologies

Microsoft Power BI for Data Visualization

Excel / CSV Data Source for importing and cleaning sales data

DAX Measures for KPIs (Total Revenue, Avg Discount, etc.)

Map Visualization for regional sales analysis

🚀 Purpose

This project demonstrates data storytelling using Power BI — transforming raw sales data into actionable business insights for better decision-making and marketing strategy improvement.
